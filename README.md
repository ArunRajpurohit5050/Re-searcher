RE-search 🔍: Search anything 🗺️, anywhere 🛰️:

Overview
It is an ai agent which can do deep researches for free and cheap💸.

How Does It Work?
It used multiple apis such as firecrawl, duckduckgo, tavily, wikipedia, arxiv, and other to get as much info as possible and give a complete synthesised answer with all the info

How to use it?📑
Just visit the website 🌐:"commingsoon.wait" or use the command "uvicorn main:app --reload" and "python -m http.server 3000"
and open localhost:3000 to use the agent local also make a .env file with all the keys🔑.

.env keys🔑
ai_key="groq key"
tavily_key = "tavily key"
gemini_key = "gemini key"
fire_key = "firecrawl key"

Note📜- use this command to install libraries "pip install fastapi uvicorn openai duckduckgo-search firecrawl-py tavily-python arxiv wikipedia pymed internetarchive"
